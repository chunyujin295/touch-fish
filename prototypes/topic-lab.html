为什么需要主题包

皮肤只还原了版式，但老板扫进眼里的是文字。导航写着「前端 / 后端 / 人工智能」、侧栏推荐「K8s 排查」、广告写「云服务器首年 89」，而正文是《内科学》——版式对了、语境错了，比版式错更容易被识破。主题包就是那套"行业语料"：站点原型、版块结构、术语口径、推荐池、广告池、评论语气，以及最关键的禁忌词。

三种版式对应什么行业

版式用在哪结构特征与可信点
blog密码 / 信息安全 / 计算机面包屑 + 作者行 + 目录 + 右侧推荐 + 底部评论。长文天然合理，代码块有位置放。
forum教育 / 医疗帖子标题 + 楼主卡 + 楼层回复（#1 #2 引用块）+ 快速回复框。楼层号、"本帖最后由…编辑"是论坛独有指纹，也顺带解释了你为什么停在这一页这么久——你在追一个讨论。
acad生物 / 数学 / 物理摘要卡 + 关键词 + 参考文献 + 讨论区 + 期刊页脚。素净、衬线标题，与人文学术站观感一致。

可信度分级

级别做法适用成本
L1 直出书原文 + 同行业壳，一个字不改书本身就属于该行业（读《国密算法原理》用密码包）0
L2 轻包装加行业小标题、术语高亮、摘要卡跨行业但可迁移（读《思考，快与慢》用教育包）规则引擎
L3 改写口吻把章节改写成"帖子体"，补提问与回复内容与行业差距大（读小说用医疗包）需本地 LLM

三类反例

医疗书 + CSDN 壳（导航全是前端后端）、小说 + Stack Overflow 壳（英文问答里夹中文叙事）、数学书 + 掘金壳（满屏无序列表装不下定理与证明）——这三种组合的违和感在 1 秒内就能被察觉，比任何细节瑕疵都致命。选主题包的第一原则不是"哪个好看"，而是这本书本来会出现在哪个社区。
