书库

把本地电子书渲染成以假乱真的社区网页

书库还是空的

把 .epub / .mobi / .txt 拖进这个窗口，或者点右上角的「导入书籍」。
书只存在你本机的数据目录里，不上传任何地方。

皮肤决定「页面长什么样」，主题包决定「聊什么」。两者必须和你在读的书同属一个行业，否则版式再像也会露馅。

站点皮肤

行业主题包

主题包替换导航、版块、推荐池、广告池、评论语气和术语口径，并带一张禁忌词黑名单。

外观跟随系统会随系统的深色 / 浅色设置自动切换，也可以固定成其中一种。书库和阅读页一起生效
应用图标替换左上角的 logo，换成你自己的图。PNG / JPG / WebP，建议正方形、不超过 2 MB；只影响书库界面
在浏览器中打开用系统默认浏览器打开同一份书库，书、进度、设置完全一致。会先把窗口收起来，和托盘的「打开网页页面」是同一个效果
全局热键任意程序里都能呼出窗口，窗口在前台时按则收起；保存后立即生效，被别的软件占用时保留原键
通知区图标右键菜单可以打开主页面、打开网页页面或退出；关掉之后只剩热键能把窗口叫回来
默认站点皮肤每次打开阅读页时使用
默认主题包决定导航、推荐位、广告与评论的行业语境
Boss Key 落点在阅读页按 Esc 直接跳转到这里，建议填一个你常开的工作页
失焦暂停阅读量切走窗口时停止数字自增，避免"后台还在涨"的破绽
阅读页快捷键关闭后只保留 Esc，其余按键交还给浏览器
Esc立即离开当前页（Boss Key）
←→上一页 / 下一页，到边界自动跨章

P换下一个主题包（Shift + P 反向）

+-正文调大 / 调小，记住选择
